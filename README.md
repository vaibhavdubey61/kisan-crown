# Kisan Crown™ Official B2B Website & Machinery Catalog

India's premier manufacturer and wholesale distributor of heavy agricultural machinery, post-harvest equipment, and commercial processing units (GTB International Pvt. Ltd., Est. 1977).

## Features
- **Main B2B Wholesale Portal (`index.html`)**: Complete 6-division machinery catalog, dealer margin simulator, and B2B wholesale inquiry desk.
- **Dedicated Product Ad Landing Pages**: High-conversion landing pages for Google Ads / Meta Ads with technical specs, unboxing checklists, customer reviews, FAQs, and 1-click WhatsApp quotes.
  - `6n-110.html` - 6N-110 Semi-Commercial Rice Mill
  - `6n-70-ultra-pro.html` - 6N-70 Ultra Pro Max (Combined Rice Mill + Cyclone Pulverizer)
  - `6n-70.html` - 6N-70 Commercial Rice Mill with Destoner
  - `6n-40.html` - 6N-40 Mini Rice Mill
  - `power-weeder-7000p.html` - 7 HP Heavy-Duty Power Weeder 7000P
  - `power-weeder-8000p.html` - 7 HP Power Weeder 8000P Pro
  - `battery-sprayer-double-motor.html` - Double Motor 12V 12Ah Battery Sprayer
  - `commercial-pulverizer-3hp.html` - 3 HP Heavy Commercial Pulverizer
  - `cold-press-oil-mill.html` - Cold Press Mini Oil Extraction Mill OM-1000
  - `feed-pellet-machine-210.html` - 210 3-Roller Feed Pellet Making Machine
  - `sugarcane-juice-machine.html` - 6-Gear Sugarcane Crusher Plant
  - `winover-cum-grader.html` - Corn Winnower Cum Grader (1500 kg/hr)
- **Netlify Routing (`_redirects`)**: Clean URL rewrites without `.html` extensions.

## Local Preview

```bash
# Python 3
python -m http.server 3000

# Or Node.js
npx serve
```
